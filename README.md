Instrucciones para ejecutar los archivos:

1. Descargar o cloná la carpeta completa del proyecto en tu computadora.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Instalá las librerias necesarias: asegurate de tener python instalado y todas libreria de las requeridas (opencv-python numpy matplotlib). En caso de no tener alguna, las podes descargar con el comando

   *pip install opencv-python numpy matplotlib*
5. Dirígete a la carpeta del proyecto en la terminal de visual y ejecuta el comando *py* (esto abrirá un interprete de python, donde podrás ejecutar el archivo).
6. Elije uno de los archivos de python:
* *problema1.py*: segmentación y clasificación automática de monedas y dados.
* *problema2.py*: segmentación de caracteres de patentes.
* *mejores_resultados.py*: segmentación de caracteres de patentes, con mayor efectividad (reforzando morfología).
Selecciona las lineas que deseas ejecutar y correlas con *ctrol + shift*
